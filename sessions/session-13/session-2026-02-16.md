## What I understood
- OLTP tables store the current operational data.
- A Data Warehouse stores summarized data for analysis.
- ETL means Extract, Transform, and Load.
- A trigger can automatically save assignment changes.
- The `tickets` table shows the current assigned agent.
- The `ticket_assignments` table keeps the full assignment history.
- `valid_to = NULL` means the assignment is still active.
- A fact table stores measurable data, like tickets created or resolved.
- A dimension table stores descriptive data, like agent name and team.
